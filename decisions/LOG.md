# Журнал решений продюсера

Каждое решение продюсера — отдельная строка. Запись не стирается: отменённое помечается «отменено владельцем, <дата>».

Это решения агента, а не слова владельца. Метка `[владелец:…]` на этот файл не опирается: слова владельца лежат в `decisions/OWNER.md` и в ответах `decisions/ESCALATIONS.md`. Счёт находок по ролям внизу ведёт дирижёр.
