# Манифест ассетов: схема строки

Манифест отвечает на вопрос «откуда это взялось и можно ли это использовать». Канонический манифест будет вестись блоком плана `[владелец:О-4]`; самого блока в плане ещё нет (задача Ж-2 в `BACKLOG.md`). В репозитории студии лежат строки-кандидаты: в файле роли, раздел «Манифест», тем же набором полей.

| Поле | Что писать |
| --- | --- |
| `id` | Короткий идентификатор: `sfx.hatch.sting`, `music.camp.theme`, `icon.journal`, `lib.spr` |
| `kind` | `sound`, `music`, `image`, `mesh`, `code`, `font` |
| `where` | Где используется: PoiId, путь в дереве Studio или экран |
| `source_type` | `creator-store` (каталог Roblox), `generated-by-code` (сделано скриптом из `tools/`), `roblox-generator` (генераторы Studio), `cc0-pack`, `oss`, `upload-own` |
| `source` | Идентификатор ассета Roblox, URL набора или `owner/repo@коммит:путь` |
| `author` | Автор или издатель |
| `license` | Точное имя лицензии и ссылка на её текст |
| `allowed_use` | Что лицензия разрешает для нас: в игре, в роликах вне Roblox, коммерчески |
| `checked` | Дата проверки лицензии и кто проверял |
| `status` | `кандидат`, `прослушано/просмотрено владельцем`, `одобрено`, `в игре`, `снято` |
| `approved_by` | Только `владелец`. Продюсер ставит статус не выше `кандидат`: звук нужно услышать, картинку увидеть, библиотеку в игру и любую загрузку решает владелец |
| `notes` | Ограничения: «только внутри Roblox», «нужна атрибуция», «не для роликов» |

## Правила лицензий

Допустимо без вопросов: MIT, Apache-2.0, BSD, ISC, Unlicense, CC0, собственная работа, каталог Creator Store для использования внутри игры.

Только по решению владельца: CC BY (нужна атрибуция), любые платные источники, загрузка собственных файлов в Roblox (нужно согласие на каждую пачку), генераторы с условиями по выручке.

Нельзя: GPL, AGPL и LGPL для кода, который попадает в игру; лицензии с пометкой «некоммерческое» (NC); репозиторий без файла лицензии; наборы, «извлечённые» из чужих игр; музыка каталога Roblox в роликах для TikTok и Shorts.

Звук никто, кроме владельца, не слышит. Поэтому статус звука выше «кандидат» ставится только после его прослушивания.
