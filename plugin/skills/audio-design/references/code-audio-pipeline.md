# Звук кодом: порядок, команды, лицензии

Звук кодом нужен в двух случаях: слот не закрывается каталогом (щелчок интерфейса, короткая музыкальная фраза) или звук должен принадлежать игре целиком, чтобы его можно было ставить в ролики вне Roblox (своя тема лагеря). Во всех остальных случаях первым идёт каталог Creator Store `[студия]`.

Главное ограничение: результат никто не слышал. Скрипт выдаёт файл и числа; годится ли звук, решает только владелец после прослушивания. До этого у файла статус `кандидат`, и слова «готово», «подходит», «одобрено» к нему неприменимы.

Устройство скриптов, проверочный прогон и ловушки библиотек описаны в `tools/audio/README.md`. Здесь — как ими пользуется роль.

## 1. Что есть

| Скрипт | Что делает | На чём | Лицензия инструмента |
| --- | --- | --- | --- |
| `tools/audio/make_sfx.mjs` | Короткие эффекты из пресета и числа-зерна; WAV 16 бит, моно | `jsfxr` 1.4.1 | Unlicense (файл `UNLICENSE` в пакете) |
| `tools/audio/make_loop.mjs` | Музыкальная петля из JSON-партитуры: MIDI, затем рендер через SoundFont; WAV 16 бит, стерео | `midi-writer-js` 3.2.1 и `spessasynth_core` 4.4.10 | MIT и Apache-2.0 |
| `ffmpeg` (программа сессии, в репозиторий не входит) | Кодирует WAV в OGG по флагу `--ogg` | — | не распространяется с проектом |

Попутные пакеты из `package-lock.json`: `@tonaljs/midi` 4.10.5, `@tonaljs/pitch` 5.0.3, `@tonaljs/pitch-note` 6.1.2, `fflate` 0.8.3 (все MIT), `stb-vorbis` 0.0.7 (Apache-2.0). Лицензии прочитаны в установленных пакетах 15–16 ноября 2026.

По тексту этих лицензий они относятся к коду инструмента, а не к звуку, который им сделан. Своё условие есть у данных: у файла SoundFont (раздел 4).

`ZzFX` (MIT) решает ту же задачу, что `jsfxr`, и в инструмент не взят: одного генератора эффектов достаточно.

## 2. Подготовка

Команды даны от корня репозитория.

```bash
(cd tools/audio && npm ci --ignore-scripts)
```

- `npm ci` ставит ровно те версии, что записаны в `package-lock.json`. `npm install` здесь не применять: у `spessasynth_core` зависимость `stb-vorbis` объявлена как `latest`, и точную версию держит только файл блокировки.
- `--ignore-scripts` обязателен: скрипты установки пакетов не выполняются.
- Команда создаёт только `tools/audio/node_modules/`. Каталог закрыт в `.gitignore` и файлом репозитория не является. Обычно установку делает дирижёр или инструментальщик; если каталога нет, роль звука выполняет эту одну команду сама. Других установок она не делает.
- Нужен Node 22 или новее. `ffmpeg` нужен только для OGG: без него скрипт оставит WAV и скажет об этом.

## 3. Эффекты: `make_sfx.mjs`

Список эффектов — файл `drafts/<шаг>/out/audio-designer/sfx-list.json`:

```json
[
  { "id": "sfx.ui.click.a", "preset": "click", "seed": 11 },
  { "id": "sfx.ui.click.b", "preset": "click", "seed": 12 },
  { "id": "sfx.ui.click.c", "preset": "blipSelect", "seed": 3, "maxSeconds": 0.2 }
]
```

```bash
node tools/audio/make_sfx.mjs \
  --out drafts/<шаг>/out/audio-designer/sfx \
  --list drafts/<шаг>/out/audio-designer/sfx-list.json --ogg
```

- `id` — идентификатор слота из листа звуков плюс буква варианта: три–пять кандидатов на слот получаются разными `seed` или разными пресетами.
- Один пресет и один `seed` всегда дают один и тот же файл. Поэтому в git идёт список, а не звук.
- Для игры по умолчанию берутся пресеты `click`, `blipSelect`, `pickupCoin`, `powerUp`, `tone`. Пресеты `laserShoot`, `explosion`, `hitHurt` названы как оружие и удары: их не использовать (ворота G4). Бриф эти ворота не открывает: исключение возможно только по ответу владельца.
- Пик каждого файла приводится к одному уровню (`--peak`, по умолчанию 0,6): в наборе нет внезапно громкого файла.
- Рядом ложится `sfx-report.json`: пресет, `seed`, полные параметры звука, длина, пик, размер, sha256. По параметрам из отчёта звук получается заново байт в байт. Отчёт перезаписывается при каждом запуске: один список — одна папка вывода.

## 4. Петля: `make_loop.mjs`

Партитура — файл `drafts/<шаг>/out/audio-designer/<id>.score.json`:

```json
{
  "id": "music.test.loop", "bpm": 80, "beatsPerBar": 4, "bars": 4,
  "tracks": [
    { "name": "lead", "program": 10, "volume": 100, "reverb": 40,
      "notes": [ { "at": 0, "dur": 1, "pitch": "E5", "vel": 70 },
                 { "at": 1, "dur": 2, "pitch": ["C4", "G4"] } ] }
  ]
}
```

`at` и `dur` — в долях от начала петли; `program` — номер инструмента General MIDI с нуля; `vel` — от 1 до 100. Петля не длиннее 120 секунд, дорожек не больше восьми.

```bash
# только MIDI: SoundFont не нужен
node tools/audio/make_loop.mjs --out drafts/<шаг>/out/audio-designer/loop \
  --score drafts/<шаг>/out/audio-designer/<id>.score.json

# рендер: путь к SoundFont даётся аргументом
node tools/audio/make_loop.mjs --out drafts/<шаг>/out/audio-designer/loop \
  --score drafts/<шаг>/out/audio-designer/<id>.score.json \
  --soundfont <путь вне репозитория>/<файл>.sf2 --ogg
```

Скрипт ничего не скачивает. Файла SoundFont в репозитории нет (`*.sf2` и `*.sf3` закрыты в `.gitignore`); его приносит владелец или инструментальщик (задача Е-2 в `BACKLOG.md`) и кладёт вне репозитория. Роль звука SoundFont сама не ищет и не скачивает: нет файла — она останавливается на MIDI и пишет об этом в черновике.

Какой SoundFont можно:

| SoundFont | Лицензия | Решение | Откуда известно |
| --- | --- | --- | --- |
| FluidR3 GM | MIT | Первый выбор для звука, который пойдёт в игру | Текст лицензии прочитан исследованием 15–16 ноября 2026 (`musescore/MuseScore`, ветка 3.x, `share/sound/FluidR3Mono_License.md`). Сам файл не скачивался и не рендерился |
| MuseScore General (`MS_General.sf2`) | MIT; в производных SoundFont нужно сохранять благодарности | Можно | То же; не скачивался |
| GeneralUser GS | Своя лицензия v2.0: для своей музыки, частной и коммерческой, без ограничений. Автор при этом пишет, что не может быть на сто процентов уверен в происхождении всех сэмплов | Только пробы. В игру — по решению владельца | `LICENSE.txt` в npm-пакете `generaluser` 1.47.1, прочитан в этом прогоне |
| VSCO-2 Community Edition | CC0 1.0 | Лицензия чистая, но это сэмплы и SFZ, а не `.sf2`: скрипт их не читает | Заметки исследования |
| TimGM6mb | GPL-2.0 | Нельзя | `LICENSES.md` в npm-пакете `pepperscore-sounds-core` 0.1.0, прочитан в этом прогоне |
| Любой файл без текста лицензии | — | Нельзя | Схема манифеста, раздел «Нельзя» |

В отчёт `<id>.report.json` скрипт пишет имя файла SoundFont, его размер и sha256: по ним строка манифеста доказывает, из какого банка сделан звук. Отрендеренная музыка содержит сэмплы банка, поэтому имя банка, версия и текст его уведомления о лицензии хранятся в поле `notes` строки манифеста. Нужно ли показывать уведомление в самой игре, решает владелец; это не юридическое заключение.

Шов петли скрипт закрывает сам: доигрывает восемь секунд после конца и складывает этот хвост с началом. В отчёте есть поле `seam`: скачок на стыке конца и начала в сравнении с обычными шагами рядом. `ok: false` или предупреждение «звук ещё не затих» — петлю владельцу не отдавать, сначала править партитуру (короче ноты в конце, меньше `reverb`).

## 5. Пределы тембра

- `jsfxr` звучит как восьмибитная приставка. Годится для щелчков интерфейса, подбора, коротких сигналов. Камень, дерево, металл, шаги им не сделать: для них каталог.
- Рендер через SoundFont даёт звук уровня General MIDI: музыкальная шкатулка, арфа, мягкий фон. На записанный саундтрек это не похоже, и разные банки звучат по-разному.
- Партитуру пишет агент, который не слышит. Гармонию можно проверить по правилам, а «цепляет ли мелодия» — нельзя. Поэтому вариантов несколько, они короткие, и отличаются одним признаком (темп, инструмент, лад), чтобы владелец мог сказать, что именно не так.
- Числа отчёта (длина, пик, средняя громкость, шов) говорят, что файл технически исправен. О качестве звука они не говорят ничего.
- Генеративные модели и платные сервисы в этот порядок не входят. MusicGen и AudioGen нельзя: веса под CC-BY-NC. ElevenLabs и Suno — платные для коммерческого использования, а платное только по согласию владельца (заметки исследования 15–16 ноября 2026).

## 6. Куда идёт результат

Всё пишется в `drafts/<шаг>/out/audio-designer/`. Внутри репозитория скрипты откажутся писать в любое другое место; вне репозитория допустима временная папка для пробы.

| Файл | В git | Зачем |
| --- | --- | --- |
| `sfx-list.json`, `<id>.score.json` | да | По ним звук получается заново |
| `sfx-report.json`, `<id>.report.json` | да | Доказательство: параметры, sha256, SoundFont |
| `*.wav`, `*.ogg`, `*.mid` | нет | Аудиофайлы в репозиторий не коммитятся; они воспроизводятся командой |
| файл SoundFont | нет | Лежит вне репозитория |

Как файлы попадают к владельцу на прослушивание, решает дирижёр. Роль перечисляет их в разделе «Что прослушать» со слотом, длиной и путём.

## 7. От файла до игры

1. Роль: список или партитура → файлы → отчёт → строка-кандидат манифеста: `source_type: generated-by-code`, в `source` — скрипт, файл списка или партитуры, `seed`, SoundFont и его sha256; `status: кандидат`.
2. Владелец слушает. Его слова записываются в звуковую библию, раздел 8.
3. Владелец даёт согласие на загрузку конкретной пачки файлов. Загружает он сам или исполнитель в чате «План» по его команде (`roblox-audio-rules.md`, разделы 3–5). Загрузка постоянная.
4. После модерации появляется идентификатор ассета. Строка манифеста в плане получает `source_type: upload-own` и этот идентификатор; статус `одобрено`, после вставки в Studio — `в игре`.

Роль звука выполняет только шаг 1. Статус выше `кандидат` она не ставит.

## 8. Что проверено прогоном

Прогон 15–16 ноября 2026, Node 22.23.4, ffmpeg 6.1.1, вывод только во временную папку вне репозитория.

- `make_sfx.mjs --demo --ogg`: четыре файла длиной от 0,064 до 0,181 с; WAV от 5 664 до 16 008 байт, OGG от 5 167 до 6 171 байт. Повторный запуск дал те же байты.
- `make_loop.mjs --demo` без SoundFont: MIDI 284 байта; независимый разбор файла подтвердил темп, инструменты на своих каналах и время каждой ноты.
- `make_loop.mjs --demo` с GeneralUser GS 1.47.1 (только для пробы): петля 12,000 с, WAV 2 116 844 байта, OGG 191 488 байт той же длины в сэмплах; рендер около четверти секунды; шов в норме; повторный рендер дал те же байты.

Не проверено: файлы `.sf3`; FluidR3 и MuseScore General; другая машина и другие версии Node и `ffmpeg`. Ни один из файлов никто не слушал.
