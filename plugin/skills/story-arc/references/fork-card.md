# Карточка развилки

Развилка — вопрос владельцу класса В: основа сюжета, которой нет в каноне. Продюсер не выбирает; не больше трёх развилок на отчёт.

```markdown
### Развилка <N>: <что решаем, одной фразой>

**Где в арке:** <акт, обновление, удар>
**Почему развилка:** <новый факт о мире / новая недоговорка / новая загадка / финал / новый герой, место, глава, событие / толкование канона>

| Вариант | Суть (2–3 строки) | Что меняется в арке и механике | Пример строк (EN, `[предложено]`) | Цена (часы, роли; `[предложено]`) | Риск |
| --- | --- | --- | --- | --- | --- |
| а | | | | | |
| б | | | | | |
| в | | | | | |

**Рекомендация:** <вариант> — <почему>
**Если ответа нет:** работа по рекомендации только в черновике; строки помечены «зависит от развилки N»
```

Проверка карточки контролёром: два-три варианта; ни в одном варианте нет ответа на загадку; пункт действительно класса В; пример строки проходит правила текста (английский, до двух коротких строк).
