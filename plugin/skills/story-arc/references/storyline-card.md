# Карточка сюжетной линии

Новая сюжетная линия (например, артель «Чёрная Скала» из задела канона) — основа сюжета: решает владелец. Карточка — развилка сценариста арки. Принятая линия получает строку в реестре линий и акты в `bibles/story/arc.md`.

| Поле | Что писать |
| --- | --- |
| Рабочее название | Нейтральное, до решения владельца |
| Одной фразой | Что игрок делает и что узнаёт |
| Зачем игре | Какой цели плана служит: D7, игра с друзьями, длина захода. Цели — только из «Метрик» канона |
| Опора в каноне | Задел, улика или недоговорка, из которой линия растёт; метка |
| Загадка | Какую из шести трогает или что это новая большая загадка (не больше одной на акт `[владелец:E-1]`) |
| Герои | Кто из пяти участвует; нужен ли новый (тогда лист героя) |
| Механика-носитель | есть / в плане / нет, по каждому акту линии |
| Акты | 2–4 строки: окно плана, что открывается, один закрытый и два открытых вопроса |
| События | Какие события плана несут линию; новых событий линия не заводит |
| Конец линии | Что игрок переживает в конце, без ответа на загадку |
| Чем рискуем | Тон, дети, сроки, часы «Плана» |

Варианты: два-три способа вести линию (или «не вести сейчас»), цена и рекомендация — по `fork-card.md`.
