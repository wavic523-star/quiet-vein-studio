# Лист героя

Новый герой — основа сюжета: его решает владелец (ворота G3). Лист заполняет сценарий арки как развилку: два-три варианта героя или один герой с двумя-тремя вариантами спорных полей. Принятый лист дирижёр переносит в `bibles/story/cast.md`, хранитель лора — строкой в реестр героев.

Существующие пять героев описаны в каноне: их лист собирается из канона дословно, с метками, без новых полей.

## Поля

| Поле | Что писать | Откуда правило |
| --- | --- | --- |
| Имя (EN) и рабочее имя (RU) | До решения владельца — нейтральное рабочее английское имя | инструкция проекта: нейтральные названия до ответа |
| Роль в лагере | Что герой делает для игрока: какую механику открывает или обслуживает | `[canon:lore-bible.md#Герои]`: колонка «Что даёт игроку» |
| Механика-носитель | есть в игре / в плане / нет. При «нет» — запрос механики и запасной вариант | `docs/STORY-ORCHESTRA.md`, раздел 5 |
| Окно появления | Окно плана из снимка; дата не придумывается | снимок канона |
| След заранее | Что игрок видит о герое за одно-два обновления до появления: предмет, записка, чужая реплика | `[предложено]`: приём живых игр, см. NOTICE |
| Силуэт и цвет-якорь | Одна фраза о силуэте, один цвет. Тёплые цвета у людей; бирюзовый только у Echo и знака the Deep | `[canon:lore-bible.md#Облик героев]` |
| Как говорит | Длина фразы, любимое слово, одна привычка речи | `[canon:lore-bible.md#Герои]`: образец колонки |
| Чего никогда не скажет | 2–3 запрета | `[предложено]` |
| Чего хочет / что прячет | Желание — открыто; недоговорка — одна, без ответа | `[canon:lore-bible.md#Голоса героев и петли сайд-историй]`: колонка «Недоговорка» |
| Связи | С кем из героев сцеплен и какой общей деталью | там же: «Связи между героями» |
| Загадка | Номер затронутой загадки или «новая — развилка» | навык `story-registers` |
| Сайд-история | Одна история в три шага — отдельным шагом у дизайнера квестов | `[canon:lore-bible.md#Рост героя и сайд-истории]` |
| Пример строк | `first`, одна `idle`, `offer` — по одной, `[предложено]` | навык `game-writing` |

## Проверка листа

- [ ] Герой не дублирует роль существующего: у каждого своя механика.
- [ ] До 15 частей, без оружия и страшных лиц `[canon:lore-bible.md#Облик героев]`.
- [ ] Недоговорка не называет ответ ни на одну загадку.
- [ ] Есть след заранее или сказано, почему он не нужен.
- [ ] Строки героя не нужны для прохождения.
