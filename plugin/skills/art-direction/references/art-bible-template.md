# Арт-библия Quiet Vein: Dig & Hatch — шаблон

Снимок канона: версия `<N>` из `canon/SNAPSHOT.txt` · Дата: `<дата>` · Статус: черновик

Девять разделов по структуре арт-библии CCGS `[oss:Donchitos/Claude-Code-Game-Studios@abc0de7:.claude/skills/art-bible/SKILL.md, MIT]`, переведённые в единицы Roblox: studs, число `Part`, `Color3.fromRGB`, имена `Enum.Material`, `Range` и `Brightness` света. Строки с меткой `[canon:…]` предзаполнены по снимку версии 760.

Как заполнять:

- Сверь версию в `canon/SNAPSHOT.txt`. Если она не 760, открой каждую строку `[canon:…]` заново: снимок мог измениться.
- Строки `[canon:…]` не переписывай и не уточняй. Метка говорит, где это записано в снимке плана. Часть блоков плана сама помечена «предложено»: их статус читается в заголовке блока, а не здесь.
- Пустая ячейка — это `____` и слова «в каноне не описано — заполняется как [предложено]». Заполняй её, только если бриф назвал это белым пятном: тогда строка получает `[предложено]` и идёт в таблицу «Новое» файла роли. Иначе оставь пустой. Пустую ячейку заметят, правдоподобную построят.
- Значения, которые уже стоят в игре, но не записаны в снимке (цвета руд, свет ярусов, размеры), не выдумывай: их снимает в Studio дирижёр. До этого в ячейке пишется «не снято в Studio».
- Арт-библия не повторяет координаты точек, раскладку частей, таблицу вариантов и карточки эффектов. Это файлы ролей окружения и обликов. Здесь правила, по которым они пишутся.

## Самопроверка арт-библии

Вопросы приёмки адаптированы из `[oss:Donchitos/Claude-Code-Game-Studios@abc0de7:.claude/docs/director-gates/ad-art-bible.md, MIT]`. Автор проходит их сам; вердикт выносит контролёр по навыку `canon-guard`.

- [ ] Цвета раздела 4 поддерживают настроение каждого состояния из раздела 2.
- [ ] Язык форм раздела 3 следует из визуального правила раздела 1.
- [ ] Стандарты раздела 8 выполнимы на телефоне в пределах бюджетов канона.
- [ ] Раздел 5 даёт достаточно, чтобы собрать фигурку, и не расписывает лишнего.
- [ ] Разделы не противоречат друг другу; найденные стыки названы в разделе 4, а не сглажены.
- [ ] Посторонний исполнитель соберёт объект по одному этому документу, не задав вопроса.
- [ ] Каждый интерактивный объект читается чёрным силуэтом на дистанции игровой камеры.
- [ ] Ни один смысл не держится только на цвете.
- [ ] Бирюзовый стоит только у Echo и знака the Deep; остальные цвета посчитаны по `dE2000`.
- [ ] Ни одна строка не объясняет и не закрывает шесть загадок.
- [ ] Каждая пустая ячейка либо осталась пустой, либо заполнена как `[предложено]` по белому пятну брифа.
