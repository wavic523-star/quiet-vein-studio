# Таблица вариантов: схема и косметика из канона

Вариант — это строка конфигурации поверх базовой модели. Таблица вставляется в раздел «Спецификация» файла роли (вид файла — `docs/CONVENTIONS.md`, раздел 6). Выписка ниже сделана по снимку канона версии 760; при другой версии каждую строку пересверить.

## 1. Схема строки

| Поле | Что писать | Правило |
| --- | --- | --- |
| `id` | Рабочий идентификатор: `pick.<слово>`, `pet.<вид>.s1`–`s3`, `plaque.<слово>` | Схема идентификаторов — рабочая, `[предложено]`; в игру и в план она идёт только после принятия. Латиница, нижний регистр |
| Имя в каноне | Имя как в каноне, с кавычками и языком оригинала | Нет имени — «имени нет». Новое имя не придумывать: его пишет хранитель лора |
| Базовая модель | Какая модель в Studio берётся за основу и сколько в ней `Part` | Число частей снимает дирижёр; без него стоит «не снято в Studio» |
| Изменённые части | Перечень: какая часть меняет размер, какая добавлена, какая убрана; итоговое число `Part` | Чем меньше, тем лучше: вариант должен собираться из той же раскладки |
| Цвета | `Color3.fromRGB(r, g, b)` для каждой изменённой части, с ролью: основной, акцент | Бирюзовый около `Color3.fromRGB(0, 200, 180)` не использовать [canon:lore-bible.md#ТЗ окружения для команды разработки]; [canon:lore-bible.md#Облик героев] |
| Материал | Имя из `Enum.Material` для каждой изменённой части | Сверить имя со списком [roblox:https://create.roblox.com/docs/reference/engine/enums/Material, 2026-11-16] |
| Акцент силуэта | Одна часть или группа, которая меняет контур; где она на модели | Ровно один. Для перекрасок по канону — «нет, исключение Л-10» |
| Эффект | «нет» | Иное — только строкой `[предложено]` с карточкой эффекта и вопросом владельцу |
| Как получить | Способ из канона, слово в слово по смыслу | Только из канона. Нет в каноне — «в каноне не описано». Цена не пишется никогда |
| Когда | Этап или окно из канона | Только из канона |
| Передано | Кому ушла смежная часть: имя и история — хранителю лора, звук — звуковой роли | — |
| Источник | Метка для каждой клетки, взятой из канона; `[предложено]` для остального | Строка без метки не принимается |

### Правило «силуэт, а не только цвет»

Вариант отличается от базовой модели и соседних вариантов контуром. Проверка для автора: описать контур словами так, чтобы по описанию можно было отличить вариант, не зная цвета («навершие в виде крюка справа», «две короткие стойки сверху»). Проверка для исполнителя после постройки: снимок варианта рядом с базовой моделью с расстояния игровой камеры на экране телефона.

Правило выведено из требования канона к героям: свой силуэт и один цвет-якорь, узнавание за 2 секунды. [canon:lore-bible.md#Облик героев] Само правило для обликов — правило навыка, в плане его нет.

Исключение: облики за вехи журнала (Л-10) канон велит перекрашивать из существующих, без новых моделей. [canon:lore-bible.md#ТЗ лор-слоя по исследованию трендов] Для них акцент не добавляется.

## 2. Что канон уже называет

Здесь только то, что написано в каноне. Пустые клетки облика — белые пятна: «в каноне не описано — [предложено]».

### Облики кирки

| `id` (рабочий) | Имя в каноне | Что канон говорит об облике | Как получить | Когда | Источник |
| --- | --- | --- | --- | --- | --- |
| `pick.starter` | имени нет: «облик кирки» в стартовом наборе | в каноне не описано — [предложено] | входит в пропуск «Стартовый набор» | MVP | [canon:events-monetization.md#Монетизация] |

| `pick.sparks-rail` | «Рельса Искры» / «Spark's Rail» | «находка главы 4»; форма в каноне не описана — [предложено] | награда сайд-истории Spark «The Lost Rail» | после запуска | [canon:lore-bible.md#Редкие предметы и скины]; [canon:lore-bible.md#Рост героя и сайд-истории]; [canon:lore-bible.md#Глава 4: Старые рельсы, текст и сайд-история Spark] |

| `pick.journal-50` | имени нет | перекраска существующего облика, новой модели нет | бесплатно за 50% завершения журнала (Л-10) | окно Б | [canon:lore-bible.md#ТЗ лор-слоя по исследованию трендов] |

«Фонарь Лукерьи» и «Lantern» названы в разных местах канона. Один это облик или два, канон не говорит: не объединять, вынести в «Открытые вопросы».

## 3. Чего в строке варианта быть не может

- Цены, скидки, срока «успей до». Цены живут в таблице «Монетизация» плана. [canon:events-monetization.md#Монетизация]
- Шанса, редкости в процентах, случайной выдачи. Платной случайной выдачи в игре нет. [canon:lore-bible.md#Редкие предметы и скины]
- Бонуса к добыче, скорости или продаже: облик ничего не меняет в игре.
- Придуманного способа получения. Если канон молчит, в клетке стоит «в каноне не описано».
- Чужих персонажей, брендов и мемов в форме или имени (ворота G5).
