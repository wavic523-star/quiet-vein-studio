# Рост и честные траты

Проверка сюжета до того, как его построят. Живые метрики здесь не читаются: их ещё нет. Цели метрик — только из `canon/events-monetization.md`, раздел «Метрики».

## Таблица по единицам

Для каждого удара арки, дня события или квеста:

| Поле | Вопрос |
| --- | --- |
| Метрика | Какой цели плана служит: D1, D7, длина первого захода, игра с друзьями. Возврат через 2–4 недели — словами, цели в «Метриках» нет |
| Причина вернуться | Что именно ждёт завтра или через неделю: незакрытая страница, яйцо, дата события |
| Кадр для ролика | Что в кадре за 5 секунд, без чтения текста |
| Повод позвать друга | Что вместе быстрее или красивее |
| Траты рядом | Что можно купить рядом; известен ли результат до покупки |
| Оценка | годится / доработать / против правил |
| Что предлагаю | Одна строка |

## Давление на детей: стоп-список

Любое «да» — оценка «против правил» и находка высокой важности:

- Цена, шанс, состав магазина в файлах сюжетных авторов (ворота G2). В файле дизайнера монетизации цена-рекомендация с ориентиром `РЫН-N` нарушением не считается: арифметику и правила смотрит проверяющий коммерции, а ты оцениваешь давление, срочность и то, как трата выглядит глазами ребёнка и родителя.
- Таймер «успей», «осталось N минут», «навсегда», «никогда больше», ложная срочность.
- Платная случайность, продажа самородков, яиц, удачи, шансов `[canon:events-monetization.md#Монетизация]`.
- Окно поверх игры, которое блокирует управление.
- Награда за просмотр, лента, внешняя ссылка, QR, свободный ввод текста.
- Страх, оружие, страшные лица (ворота G4).
- Кража у других игроков; соревнование за общую жилу.

Сомнение между «продаст лучше» и «давит на ребёнка» решается против давления.

## Лор не мешает игре

- Лор-текст в первые 10–15 минут — находка (строки канона глав 0–1 не в счёт: противоречие 13 в находках).
- Обязательное чтение для прохода — находка.

## Аналитика

Назови события аналитики, по которым будет виден эффект единицы: имя и смысл. Реализует чат «План».

## Вид находки

`важность (высокая, средняя, низкая) → место в черновике → что предлагаю`. Находки — вход для контролёра и продюсера; вердикт шага выносит контролёр.
