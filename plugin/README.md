# qv-studio

Плагин студии сюжета и оформления игры Quiet Vein: Dig & Hatch. Даёт оркестр из двенадцати ролей-агентов и тринадцать навыков: арка по обновлениям, события и квесты, игровой текст, реестры истории, а затем стиль, сцены, облики, эффекты, звук и музыка. Каждое утверждение в их работе привязано к канону или помечено как новое.

Работает только вместе с репозиторием студии `wavic523-star/quiet-vein-studio`: роли читают снимок канона в `canon/` и пакет контекста шага, пишут черновики в `drafts/`. Как пользоваться оркестром — `docs/GUIDE.md` репозитория.

Версия **0.4.2**.

## Роли

| Агент | Модель | Что делает |
| --- | --- | --- |
| `narrative-designer` | sonnet | Арка, глава, оболочка большого события, лист нового героя, карточка линии; основу выносит развилками |
| `quest-event-designer` | sonnet | Сайд-истории, задания соло и вместе, дни события, коллекции наград без цен, запросы механики |
| `writer` | sonnet | Все слова для игрока одной таблицей строк |
| `lore-keeper` | sonnet | Реестры загадок, обновлений, сайд-историй, героев и линий; аудит строк по показанному |
| `growth-reviewer` | sonnet | Причина вернуться, кадр для ролика, повод позвать друга, честные траты |
| `continuity-reviewer` | sonnet | Проверка по канону, вердикт шага |
| `producer` | sonnet | Решения за владельца по мелкому, вопросы владельцу по критичному |
| `art-director` | модель сессии | Стиль шага, арт-библия, 2D кодом |
| `environment-designer` | модель сессии | Сцены и объекты из Parts |
| `skins-vfx-designer` | модель сессии | Облики строками конфигурации, карточки эффектов |
| `audio-designer` | модель сессии | Звуковая библия, лист звуков, кандидаты из каталога, звук кодом |
| `toolsmith` | модель сессии | Чужой код и инструменты: лицензия, закрепление, адаптация |

У каждой роли только инструменты из её шапки: Roblox Studio, документа плана, памяти и запуска агентов нет ни у одной.

## Навыки

| Навык | Для чего |
| --- | --- |
| `orchestra` | Дирижёр: шаг от брифа до пакета для плана, кого и как звать, границы записи |
| `owner-proxy` | Что можно решить за владельца, что вынести ему |
| `canon-guard` | Метки источников, ворота G1–G8, порядок проверки, схема манифеста ассетов |
| `story-arc` | Арка по актам, развилки основы, голоса героев, лист героя, карточка линии |
| `quest-event-design` | Квесты, кооп, события по дням и размерам S/M/L, коллекции без цен, карта синхронизации |
| `game-writing` | Игровой текст: одна таблица строк, виды и мерки длины, голоса, три вопроса о загадках |
| `story-registers` | Четыре реестра и проверки строк по показанному |
| `growth-review` | Удержание, ролик, друг, стоп-список давления на детей |
| `art-direction`, `environment-spec`, `skins-vfx`, `audio-design` | Оформление |
| `oss-adapt` | Как взять открытый репозиторий |

Хуков, серверов MCP и автозапускаемых скриптов в плагине нет.

## Как пользоваться

В сессии чата «Сюжет» с подключённым репозиторием: «Мини-сюжет „Звездопада“, 13–14 декабря, строка Л-7», «Пропиши акт до 4 января», «Нужен герой для витрины», «Проверь черновики шага по канону». Как ставить задачи, маршруты и расход — `docs/GUIDE.md`, разделы 3, 10, 11.

## Границы

- Роли не пишут в Roblox Studio и в план. Строит чат «План» после принятия владельцем.
- Решение продюсера или дирижёра ничего не делает каноном: строка остаётся `[предложено]`, пока владелец не принял подсказку в плане.
- Слова владельца берутся только из плана и `decisions/` репозитория.
- Цены, сохранения, публикацию, траты, загрузки, основу сюжета и ответы на загадки роли не решают.
- Звук слышит только владелец.
