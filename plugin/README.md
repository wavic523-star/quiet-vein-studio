# qv-studio

Плагин студии сюжета и оформления игры Quiet Vein: Dig & Hatch. Даёт два оркестра с общим дирижёром — семнадцать ролей-агентов и восемнадцать навыков: арка по обновлениям, события и квесты, игровой текст, реестры истории; коммерция — ориентиры рынка, календарь, каталог наград и платного, продвижение; а затем стиль, сцены, облики, эффекты, звук и музыка. Каждое утверждение в их работе привязано к канону или помечено как новое.

Работает только вместе с репозиторием студии `wavic523-star/quiet-vein-studio`: роли читают снимок канона в `canon/` и пакет контекста шага, пишут черновики в `drafts/`. Как пользоваться оркестром — `docs/GUIDE.md` репозитория.

Версия **0.5.2**.

## Роли

| Агент | Модель | Что делает |
| --- | --- | --- |
| `narrative-designer` | opus | Арка, глава, оболочка большого события, лист нового героя, карточка линии; основу выносит развилками |
| `quest-event-designer` | opus | Сайд-истории, задания соло и вместе, дни события, коллекции наград без цен, запросы механики |
| `writer` | opus | Все слова для игрока одной таблицей строк |
| `lore-keeper` | opus | Реестры загадок, обновлений, сайд-историй, героев и линий; аудит строк по показанному |
| `growth-reviewer` | opus | Причина вернуться, кадр для ролика, повод позвать друга, честные траты |
| `continuity-reviewer` | opus | Проверка по канону, вердикт шага |
| `producer` | opus | Решения за владельца по мелкому, вопросы владельцу по критичному |
| `art-director` | opus | Стиль шага, арт-библия, 2D кодом |
| `environment-designer` | opus | Сцены и объекты из Parts |
| `skins-vfx-designer` | opus | Облики строками конфигурации, карточки эффектов |
| `audio-designer` | opus | Звуковая библия, лист звуков, кандидаты из каталога, звук кодом |
| `toolsmith` | opus | Чужой код и инструменты: лицензия, закрепление, адаптация |
| `market-analyst` | opus | Что делает рынок похожих игр и что говорят правила Roblox сегодня; строки ориентиров `РЫН-N` |
| `liveops-planner` | opus | Что и когда выходит в окне, зачем вернуться, где место награды и платного; строки календаря `КАЛ-N` |
| `monetization-designer` | opus | Что наградой, что платно и по какой цене-рекомендации; строки каталога `КАТ-N`, сводная таблица этапа |
| `promo-strategist` | opus | Чем это показать, кому и при каких метриках запускать рекламу; строки `ПРО-N`, набор для чата «Продвижение» |
| `commerce-reviewer` | opus | Верны ли цифры, правила Roblox, арифметика и канон денег; находки |

У каждой роли только инструменты из её шапки: Roblox Studio, документа плана, памяти и запуска агентов нет ни у одной.

| Навык | Для чего |

| `quest-event-design` | Квесты, кооп, события по дням и размерам S/M/L, коллекции без цен, карта синхронизации |
| `game-writing` | Игровой текст: одна таблица строк, виды и мерки длины, голоса, три вопроса о загадках |

| `growth-review` | Удержание, ролик, друг, стоп-список давления на детей |
| `art-direction`, `environment-spec`, `skins-vfx`, `audio-design` | Оформление |
| `oss-adapt` | Как взять открытый репозиторий |
| `market-benchmarks` | Ориентиры рынка `РЫН-N`: что делает рынок похожих игр и что говорят правила Roblox |

| `commerce-check` | Проверка коммерции: правила Roblox, арифметика, источники, канон денег |

Хуков, серверов MCP и автозапускаемых скриптов в плагине нет.

## Как пользоваться

В сессии чата «Сюжет» с подключённым репозиторием: «Мини-сюжет „Звездопада“, 13–14 декабря, строка Л-7», «Пропиши акт до 4 января», «Нужен герой для витрины», «Проверь черновики шага по канону». Как ставить задачи, маршруты и расход — `docs/GUIDE.md`, разделы 3, 10, 11.

## Границы

- Роли не пишут в Roblox Studio и в план. Строит чат «План» после принятия владельцем.
- Решение продюсера или дирижёра ничего не делает каноном: строка остаётся `[предложено]`, пока владелец не принял подсказку в плане.
- Слова владельца берутся только из плана и `decisions/` репозитория.
- Цены, сохранения, публикацию, траты, загрузки, основу сюжета и ответы на загадки роли не решают.
- Звук слышит только владелец.
