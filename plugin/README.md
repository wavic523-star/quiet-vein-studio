# qv-studio

Плагин студии оформления игры Quiet Vein: Dig & Hatch. Даёт оркестр ролей-агентов и навыки, с которыми они готовят всё, что видит и слышит игрок: стиль, сцены, облики, эффекты, звук, музыку и сюжетные реестры. Каждое утверждение в их работе привязано к канону или помечено как новое.

Плагин работает вместе с репозиторием студии: роли читают снимок канона в `canon/` и пишут черновики в `drafts/`.

## Состав

| Навык | Для чего |

| `owner-proxy` | Решения вместо владельца: что можно решить, что вынести ему |
| `canon-guard` | Метки источников, жёсткие ворота, порядок проверки, схема манифеста ассетов |
| `art-direction` | Арт-библия в единицах Roblox и 2D-графика кодом |
| `environment-spec` | Спецификация сцены и объекта из Parts, матрица ярусов |
| `skins-vfx` | Таблица вариантов обликов и карточка эффекта |
| `audio-design` | Звуковая библия, лист звуков, музыка событий, звук кодом, правила Roblox |
| `story-registers` | Реестры загадок, обновлений и сайд-историй |
| `story-arc` | Арка по актам и обновлениям, развилки основы, опоры голоса героев |
| `quest-event-design` | Квесты соло и вместе, события по дням, коллекции наград без цен, карта синхронизации |
| `growth-review` | Причина вернуться, кадр для ролика, честные траты, стоп-список давления |

| Агент | Роль |
| --- | --- |
| `producer` | Заместитель владельца |
| `art-director` | Стиль шага, первым на визуальных шагах |
| `environment-designer` | Сцены и объекты |
| `skins-vfx-designer` | Облики и эффекты |
| `audio-designer` | Звук и музыка |

Хуков, серверов MCP и автозапускаемых скриптов в плагине нет.

## Как пользоваться

В сессии с подключённым репозиторием студии:

- «Запусти оркестр: оболочка лагеря» — полный шаг оформления.
- «Проверь черновики шага по канону» — только проверка.
- «Реши за меня по шагу» — решения продюсера и вопросы владельцу.
- «Подбери звук для вылупления» — кандидаты из каталога и лист звуков.
- «Возьми библиотеку spr под Roblox» — проверка лицензии и закреплённая копия.

## Границы

- Роли не пишут в Roblox Studio и в план. Строит один исполнитель после команды владельца. Если роль запущена не как агент плагина, а обычным агентом по файлу роли, список её инструментов не действует: дирижёр обязан дать блок ограничений и сверить изменённые пути.
- Решение продюсера ничего не делает каноном: строка остаётся `[предложено]`, пока владелец не принял подсказку в плане.
- Слова владельца берутся только из плана и из `decisions/OWNER.md` репозитория.
- Продюсер не решает цены, сохранения, публикацию, траты, загрузки и основу сюжета.
- Звук слышит только владелец: без его прослушивания звук остаётся кандидатом.
