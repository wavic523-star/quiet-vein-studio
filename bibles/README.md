# Принятые документы

Сюда переезжают черновики со статусом «принят в репозитории»: арт-библия, звуковая библия, сюжетные реестры, спецификации сцен и обликов. Это ещё не канон. Строки `[предложено]` сохраняют эту метку и здесь: решение продюсера её не снимает. Каноном документ становится, когда его подсказка принята владельцем в плане; тогда дирижёр отдельным коммитом ставит в шапке «принято владельцем, план версии <N>».

Править файлы здесь можно только через шаг оформления: черновик, проверка, решение.
