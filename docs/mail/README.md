Копии документов, которые чат «Сюжет» кладёт в документы проекта для чатов «План» и «Продвижение». Оригинал — документ проекта; копия здесь нужна, чтобы чаты видели почту и в знаниях проекта из ветки `main`.

| `2026-11-16-otvet-plan.md` | `claude/Сюжет — ответ План 2026-11-16.md` | «План» | Всё за 16 ноября для «Плана»; заменяет «Сюжет — ответ чатам 2026-11-16» и «… вечер» |

Как называть почту: исходящее — `claude/Сюжет — пакет <дата>.md`; ответ — `claude/Сюжет — ответ <Кому> <дата>.md` (инструкция проекта, раздел «Чаты проекта»). Ответы других чатов «Сюжету» записываются в `decisions/CHATS.md`.

Исследования, на которые ссылаются пакеты, лежат в `docs/research/`:

- `2026-11-16-offer-pool.md` — пул предложений ПУ-1…ПУ-12 с ответами владельца (документ проекта `pool.md`).
- `2026-11-16-cosmetics-and-promo.md` — исследование сюжетной косметики и продвижения (документ проекта «Сюжетная косметика и продвижение Roblox.md»).

Эти копии — не канон. Канон — план.
