# Правки к инструкции проекта, плану и навыкам

Записано 16 ноября 2026 по просьбе владельца заранее найти места, которые начнут спорить с работой чата «Сюжет», когда готовый сюжет пойдёт в реализацию `[владелец:О-17]`. Исправлено по независимой проверке того же дня. Здесь только предложения `[предложено]`. Инструкцию проекта меняет владелец; план меняется подсказками чата, который владеет разделом; навык аккаунта `roblox-lore-writer` — через карточку предложения навыка.

Пока правки не внесены, там, где инструкция спорит с работой чата «Сюжет», действует запись владельца из `decisions/OWNER.md`; где записи нет — вопрос владельцу (`docs/STORY-RULES.md`, «Старшинство»).

Обозначения: И — инструкция проекта, ПП — правка плана, Н — навык. Вопросы владельцу — E-1…E-3 в `decisions/ESCALATIONS.md`. Статусы: `не внесено`, `внесено (дата)`, `отклонено (дата)`, `ждёт ответа`.
