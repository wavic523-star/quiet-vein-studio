# Тесты навыков

Проверочные запросы к навыкам студии в формате `claude plugin eval` (папка на случай: `prompt.md`, `case.yaml`, `graders/`, при необходимости `files/` и `place-files.sh`).

Тесты лежат вне плагина намеренно. В файлах `files/` стоят подложенные нарушения: выдуманный ответ на загадку под меткой канона, цена в Robux, неверный бюджет. В плагине и в настоящей папке `drafts/` им не место.

Как запускать:

1. Сделать одноразовую копию репозитория без `.git`.
2. В копии выполнить `place-files.sh` случая (в настоящем клоне скрипт остановится).
3. Дать агенту запрос из `prompt.md`; для сравнения — второй прогон в копии без папки `plugin/`.
4. Сверить результат с утверждениями из `graders/`.

Первый прогон (версия плагина 0.1.0, 16 ноября 2026) описан в `docs/SETUP.md`, раздел «Что проверено». После него случай продюсера изменён: убран пункт с ценой, образец проверки приведён к правилу «нарушение ворот — REJECT».

Что ещё не сделано (задача Б-6): в запросах тестов нет блока ограничений запасного пути; образец `review.md` в случае продюсера не содержит счётчиков меток владельца и блоков «(предложено)»; случаи слишком лёгкие и не различают работу с навыком и без.
