# Проверка метки шины в `tools/lint_tags.py`

Случай для скрипта, не для навыка. В `case.txt` три подложенные метки шины: одна есть в соседней выгрузке `bus.md`, второй там нет, третья записана не по образцу. Файл с метками нарочно `.txt`: общий прогон скрипта по `tests/` читает только `.md` и не падает на подложенных ошибках.

Запуск из корня репозитория:

```
python3 -I tools/lint_tags.py tests/tools/lint-tags-bus/case.txt
```

Ожидается код возврата 1 и вывод из `expected.txt`.
