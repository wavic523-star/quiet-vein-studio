# Quiet Vein Studio

Мастерская оформления игры **Quiet Vein: Dig & Hatch** («Лагерь старателя»): визуал, окружение, облики, эффекты, звук, музыка и сюжетные реестры. Репозиторий закрытый.

Канон игры живёт в плане: https://claude.ai/artifact/PYAV7Z6Ak4zjBRFodgk38j. Здесь лежит всё промежуточное. В план попадает только то, что прошло проверку по канону и решение продюсера или владельца, поэтому случайная выдумка агента остаётся черновиком, а не становится ТЗ.

## Как устроено

```
canon/        снимок плана, только чтение (версия в SNAPSHOT.txt)
drafts/       черновики шагов оформления: бриф, файлы ролей, проверка, решение
bibles/       принятые документы: арт-библия, звуковая библия, реестры, спецификации
decisions/    слова владельца (OWNER.md), журнал решений продюсера, вопросы владельцу
third_party/  закреплённые копии чужого открытого кода и текста, с лицензиями
tools/        скрипты студии: снимок канона, проверка меток, звук кодом
plugin/       плагин qv-studio: роли-агенты и навыки
docs/         соглашения, настройка, справка проекта (пересказ плана, не снимок)
tests/        проверочные запросы к навыкам; лежат вне плагина намеренно
BACKLOG.md    подзадачи студии
```

## Путь результата

`черновик` в `drafts/` → `проверен` контролёром → `принят в репозитории` (переезжает в `bibles/`) → `принято владельцем` (подсказка принята владельцем). Строить в Roblox Studio можно только то, что дошло до статуса «в плане».

## Оркестр

| Роль | Агент | Что делает |
| --- | --- | --- |
| Дирижёр | основная сессия, навык `orchestra` | Ведёт шаг, зовёт роли, готовит пакет для плана |
| Продюсер | `producer`, навык `owner-proxy` | Решает вместо владельца некритичное, остальное выносит владельцу |
| Арт-директор | `art-director`, навык `art-direction` | Стиль шага: палитра, силуэты, бюджеты; 2D-графика кодом |
| Окружение | `environment-designer`, навык `environment-spec` | Спецификации сцен и объектов из Parts |
| Облики и эффекты | `skins-vfx-designer`, навык `skins-vfx` | Таблица вариантов обликов, карточки эффектов |
| Звук | `audio-designer`, навык `audio-design` | Звуковая библия, лист звуков, музыка событий, звук кодом |
| Хранитель лора | `lore-keeper`, навык `story-registers` | Реестры загадок, обновлений и сайд-историй, строки по лору |
| Инструментальщик | `toolsmith`, навык `oss-adapt` | Берёт открытые репозитории, проверяет лицензию, адаптирует под Roblox |
| Контролёр | `continuity-reviewer`, навык `canon-guard` | Сверяет черновики с каноном, выносит вердикт с доказательствами |

Ролям запрещено писать в Roblox Studio и в план. Когда роль запущена как агент плагина, этих инструментов у неё быть не должно (не проверено до установки плагина). Когда она запущена запасным путём (обычный агент читает файл роли), запрет держится только на тексте запроса и на сверке изменённых путей: см. `docs/SETUP.md`. В Studio пишет один исполнитель и только по команде владельца.

## С чего начать

1. Настройка: `docs/SETUP.md`.
2. Правила и форматы: `docs/CONVENTIONS.md`.
3. Что делать дальше: `BACKLOG.md`.
4. Запуск шага: в сессии с этим репозиторием сказать «запусти оркестр: <что оформляем>».

Полного шага с возвратом, продюсером и пакетом для плана ещё не было.
