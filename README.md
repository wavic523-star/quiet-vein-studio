# Quiet Vein Studio

Мастерская сюжета и оформления игры **Quiet Vein: Dig & Hatch** («Лагерь старателя»): арка по обновлениям, события, квесты соло и с друзьями, игровой текст, а затем сцены, облики, эффекты, звук и музыка. Репозиторий закрытый; пишет в него только чат проекта «Сюжет» и владелец.

Канон игры живёт в плане: https://claude.ai/artifact/PYAV7Z6Ak4zjBRFodgk38j. Здесь — всё промежуточное. В план попадает только то, что прошло проверку по канону и решение владельца, поэтому выдумка агента остаётся черновиком, а не становится ТЗ.

**С чего начать:** `docs/GUIDE.md` — методичка оркестра: роли, маршруты, как ставить задачи, расход, что проверено.

## Что где лежит

```
canon/        снимок плана, только чтение (версия в SNAPSHOT.txt), обновляет tools/canon_snapshot.py
drafts/       шаги: бриф, пакет контекста, файлы ролей, проверка, решение, пакет для плана
bibles/       принятое: bibles/story/ (арка, главы, события, квесты, герои, реестры, карта синхронизации), арт- и звуковая библии
decisions/    слова владельца (OWNER.md), вопросы и ответы (ESCALATIONS.md), журнал решений (LOG.md)
docs/         GUIDE.md — методичка; CONVENTIONS.md — метки и ворота; ROLE-DIGEST.md — памятка роли;
              PROJECT-INSTRUCTION.md — инструкция проекта для вставки; project-readme.md — пересказ плана
plugin/       плагин qv-studio: 12 ролей-агентов и 13 навыков
toolkit/      навыки чата «План»: qv-plan-reader, qv-big-task
tools/        context_pack.py, lint_strings.py, lint_tags.py, canon_snapshot.py, звук кодом
third_party/  NOTICE.md: что взято из открытых репозиториев и под какой лицензией
tests/        проверочные запросы к навыкам
BACKLOG.md    задачи студии и сроки
```

## Путь результата

`черновик` в `drafts/` → `проверен` контролёром → `принят в репозитории` (переезжает в `bibles/`) → `выбран владельцем` (ответ на развилку) → `принято владельцем` (подсказка принята в плане). Строить в Roblox Studio можно только принятое владельцем; строит чат «План».

## Оркестр одной строкой на роль

| Группа | Роли |
| --- | --- |
| Сюжет | сценарист арки `narrative-designer`, дизайнер квестов и событий `quest-event-designer`, сценарист-диалогист `writer`, хранитель лора `lore-keeper`, рост и честные траты `growth-reviewer` |
| Контроль | контролёр `continuity-reviewer`, продюсер `producer` |
| Оформление | `art-director`, `environment-designer`, `skins-vfx-designer`, `audio-designer` |
| По нужде | инструментальщик `toolsmith` |

Дирижёр — основная сессия чата «Сюжет». Роли пишут только свой файл в папке шага; Roblox Studio, плана и памяти у них нет. Подробно — `docs/GUIDE.md`, разделы 2–3.

## Плагин

Каталог одного плагина: `.claude-plugin/marketplace.json`, сам плагин — `plugin/`. Поставить можно файлом `qv-studio.plugin` из чата или подключив репозиторий как каталог плагинов. Версия и состав — `plugin/README.md`.

## Правила репозитория

`CLAUDE.md`: ветка `claude/Сюжет`, в `main` — запросом на слияние, сливает владелец; один коммит — одно действие; без хуков, `.claude/settings.json`, `.mcp.json` и чужих исполняемых файлов; чужое — через навык `oss-adapt` и запись в `third_party/NOTICE.md`.
