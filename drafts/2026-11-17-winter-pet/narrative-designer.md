## Развилки

### Развилка 1: каким будет зимний питомец «Ночи фонарей»

**Где в арке:** окно А–Б, зимнее событие, удары 1–3.
**Почему развилка:** новый вид существа в мире (основа, класс В). В плане есть только слова «зимний питомец» `[canon:events-monetization.md#События и календарь]`.
**Общее для всех вариантов:** яйцо гарантировано за 5-й фонарь, без шанса и не с урожая зимней грядки. Вылупление бесплатное `[чат:Ч-28]`. Бонусы только по общим правилам питомцев `[владелец:E-3]`, по брифу. Палитра тёплая, без бирюзы `[владелец:E-13]`, по брифу. Питомец не рассказывает о прежних жителях: история события ограничена счётом фонарей `[canon:lore-bible.md#Главы и грайнд]` (арка части 1).
