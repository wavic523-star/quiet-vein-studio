# Прогон строк через roblox-lore-writer: три запроса «Плана»

Шаг: 2026-11-16-plan-asks · Дата: 16 ноября 2026 · Снимок канона: версия 796 · Кто: дирижёр

Навык владельца `roblox-lore-writer` применён с заменой из методички (`docs/GUIDE.md`, раздел 3, шаг 8): лор-библия читается из снимка `canon/lore-bible.md`, новое не дописывается в план, а идёт подсказкой.

| Ключ | Пункт навыка | Итог |
| --- | --- | --- |
| Таблицы A и B (14 строк канона) | Текст дословно из канона, меняются только условия показа; противоречий с лором нет | проходит |
| `echo.n7` | 31 знак, записка, Echo не говорит — только пишет `[canon:lore-bible.md#Герои]`; интонация как у `echo.n4` «I liked that». Правило «записка Echo заканчивается вопросом» `[canon:lore-bible.md#Виральные крючки сюжета]` не выполнено — как и у `echo.n1`, `echo.n2`, `echo.n4` (пробел канона, `bibles/story/registers/updates.md`, раздел 4) | проходит, наблюдение ниже |
| `nail.ms.75` | 55 знаков, две фразы; голос Old Nail — ворчит коротко, сухо шутит `[canon:lore-bible.md#Герои]` | проходит |
| Подписи вех (4) | До 43 знаков; «Pickaxe» в интерфейсе, валюта nuggets — по словарю канона; без цен, шансов и срочности | проходит |
| Правка лор-библии о Crystal | Записывает решение владельца из плана (`[canon:work-plans.md#Шаг 6: первая минута]`) и не объясняет связь Crystal с Deep | проходит |

Наблюдение для владельца, не замечание: если записки Echo должны кончаться вопросом, вариант `echo.n7` — «Pages are filling. Do you read them too?» `[предложено]`. Выбор за владельцем; в подсказку идёт текст диалогиста.

Длина на настоящем экране не проверена: это делает чат «План» при переносе строк в модуль `Strings`.
